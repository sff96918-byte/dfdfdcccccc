Message

One line equals one bot message step. Line 1 is first message, line 2 is second reply, line 3 is third reply, and so on.

Select Chat Mode:
Each new line is the next message the bot sends for that conversation step. Template format: {hello|hi|helo}{how|hw}.
Loads multiple chat sequence files (.txt) from a folder. The bot picks a random sequence per user.
TXT data is initialized when EVAChat Flow starts.
Base URLs: OpenAI https://api.openai.com/v1 · Groq https://api.groq.com/openai/v1 · OpenRouter https://openrouter.ai/api/v1 · Gemini https://generativelanguage.googleapis.com/v1beta/openai · DeepSeek https://api.deepseek.com/v1
EVAChat Flow is a stateful TXT-driven conversation engine. Edit data/eva_chat/input/ for user-message triggers and data/eva_chat/output/ for reply pools. The same file name connects a trigger category to its replies (see docs/CHAT_ENGINE_MAPPING.md). Fill the Usernames list: share_snap.txt uses %username%. Changes are loaded when the bot starts.
