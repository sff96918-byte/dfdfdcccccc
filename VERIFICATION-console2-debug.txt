What revision 22 adds over 21 (the debug pass - no behaviour was removed):
  * Every stuck-state log line now says where the bot was looking. `DOM WAIT`,
    `SEND PAUSED` and `START WAIT` end with
    `probe[phase=... can_send=... route=/...]`: the in-page probe plus the page
    ROUTE (path only - query and fragment are dropped, so a token or a chat id
    can never leak into a log line or a bundle).
  * The DEBUG bundle (`chitchat-debug-<time>.json`) is now a full report instead
    of a snapshot: a `privacy` note, the same CHECK SYSTEM list as the Overview
    tab (`checks`), what the runner was really told to do (`effective`: chat
    mode, sequence count, usernames saved/needed, first-message mode + burst,
    reply delay, skip-if-no-reply, page scan interval - all in seconds), the run
    state (`run`: bot/user lines, paused workers, chats, single next action),
    one whitelisted row per worker (state, activity + note, paused, counts,
    chat) and chat stats + sessions.
  * CHECK SYSTEM gained three preflight checks that name the settings behind a
    run that looks stuck: `timings` (skip-if-no-reply shorter than the reply
    delay leaves chats before their own reply is due), `page-scan` (a page scan
    slower than 2 s) and `message-mode` (folder mode with nothing loaded, or
    `%username%` / `{snap}` with an empty Usernames list). Every one prints the
    numbers it judged; PASS also says what was measured.
  * Two earlier silent failure modes were removed: a page whose author cannot be
    resolved is retried instead of dropping the row, and a stalled send is
    reported with the reason it stalled.
